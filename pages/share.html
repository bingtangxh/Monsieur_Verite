启用长时间共享支持 

如果应用支持的是上传可能需要一些时间的格式，例如图像或视频，则需要此 API。 用户应该能关掉应用，同时在后台继续上传，完成其他操作。 为了使关闭行为正常工作，您需要向分享平台汇报“已完成获取用户输入”。 在您调用此方法后，用户可以返回分享面板，在分享进度列表中查看您的应用。



这个 API 是可选的，帮助 Windows 优化系统的资源使用。 如果您已经完成了从数据包中提取数据，您应该汇报“数据已检索”，以便 Windows 可以根据需要暂停或终止来源应用，以回收系统资源。



这个 API 也是可选的，帮助 Windows 优化系统的资源使用。 如果您调用了 Windows Runtime 后台传输类来上传您的内容，则应汇报此信息。 然后，Windows 可以在必要时暂停您的应用以回收系统资源。 如果您使用此 API，那么应该先汇报“开始”，后汇报这个“已提交至后台任务”。



如果由于任何原因，长时间运行的共享未成功并且在后台给失败了，应用应当是汇报“失败”，并包含一条关于用户如何恢复错误的消息。 当用户返回共享面板时，他们可以在进度列表中看到您的消息。 如果您的应用在前台可见，那绝对不能汇报“错误”。
